
# 🏥 Sistema de Clínica Médica

📌 Descrição

O Sistema de Clínica Médica é uma aplicação desenvolvida para facilitar o gerenciamento de clínicas médicas. Ele permite o cadastro e gerenciamento de funcionários, pacientes, agendamentos, prontuários e especialidades, além de contar com um sistema de login para controle de acessos.

## ⚙️ Funcionalidades

#### 🏥 Gerenciamento de Clínica
- Cadastro, edição, listagem e exclusão de funcionários
- Cadastro e gerenciamento de especialidades médicas

#### 📅 Agendamentos

- Criar agendamentos para pacientes
- Alterar datas de consultas
- Cancelar agendamentos

#### 🏷️ Prontuários Médicos
- Registro de consultas e diagnósticos
- Histórico médico dos pacientes

#### 🔐 Sistema de Acesso
- Cadastro de perfis (médicos, recepcionistas, administradores, pacientes)
- Sistema de login e autenticação
- Controle de permissões conforme o tipo de usuário

## 💻 Oque foi ultilizado?
#### Ultilizei :
- Java, Intellij e NetBeans

- Git para o versionamento
